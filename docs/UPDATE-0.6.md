# Контур 0.6 — согласованный объём

- [x] Воронки снизу забирают только результат обработки; стороны автоматизации понятны относительно фасада.
- [x] Конвейеры: клавиша G для уклона, продолжение со свободного конца, понятное направление разделителя, привод не светится.
- [x] Усиленный сундук: 36 ячеек, образец на фасаде через GUI, без энергии, повышенная взрывостойкость.
- [x] Новые утверждённые спрайты пластин, молота, кусачек и неизолированной проволоки.
- [x] Молот: 32 операции, рецепт 2 железа + 3 палки. Кусачки: ручная нарезка пластин.
- [x] Каучуковый одуванчик: корни/семена, зрелый урожай 1 корень + 1 семя + 60% второе; незрелый ничего; группы 3–6 на 12–20 чанков в равнинах/подсолнечных равнинах/лугах.
- [x] 2 корня + молот → каучук; пресс 1 корень → каучук (80 тиков, 8 TE); печь → резина.
- [x] Медная пластина → 4 проволоки кусачками либо резчиком металла (80 тиков, 8 TE, буфер 300 TE и аккумулятор).
- [x] Резина в центре + 4 проволоки крестом → 4 изолированных провода.
- [x] Олово: каменная/глубинная руда; Y -32..80, пик 24, 8 попыток/чанк, жилы около 4–7; каменная кирка, удача, шёлковое касание.
- [x] Рудное олово (один кусок), дроблёное олово, слиток, пластина, блок из слитков. Без блока рудного олова.
- [x] Переплавка/дробление/пресс для олова, упаковка слитков. Новые базовые машинные крафты пока отложены.
- [x] Серверные и клиентские проверки, сборка JAR.

Будущие сплавы, генетика, жидкости, костюм и генераторы не входят в это обновление.

Проверено: 38 JUnit + 70 серверных GameTest, три клиентских сценария.
Сборка: `dist/kontur-0.6.0.jar`. Снимки интерфейсов: `docs/screenshots`.

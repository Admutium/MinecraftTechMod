# Контур 0.8.0 — интерфейсы костюма и локальное освещение

Станция разделена на обслуживание и модификации в одном компактном окне 380×240.
Восемь веток имеют граф зависимостей, шкалу изученных уровней и карточку выбранного узла.
Сервер проверяет зависимости при обычной прокачке. Уже изученные улучшения сохраняются;
кнопка открытия всех улучшений остаётся доступна для тестирования.

Прокачка **бесплатная**. «Проект цены» — предварительное предложение, предметы не списываются.
В креативе под заголовком карточки и в подсказке узла отображаются идентификаторы грейдов,
например `techmod:suit/run/4`. Это постоянные идентификаторы улучшений для обратной связи,
а не отдельные предметы для команды `/give`. В подсказке перечислены все грейды узла.

Tab открывает одну страницу всех переключателей. Цвет показывает состояние; закрытые
способности недоступны, причина отображается в подсказке. Нативный автоповтор клавиши
не закрывает и не открывает окно повторно. Есть прямой выбор полёта, настройки радиуса
магнита и кнопка фильтра сканера. Переназначение клавиш сохраняется.

Фильтр сканера доступен вдали от станции. Выбирается добываемый ресурс с иконкой;
обычная и глубинная руды объединены. Например, «Рудное железо» выбирает обе железные
руды, лазурит отображается лазуритом, а не блоком руды. Для золота учитывается и незерская
руда. Поддерживаются поиск по имени и ID, страницы, сброс на все руды. Старые фильтры
по ID блоков продолжают работать. Ресурсы сторонних модов с обычными названиями
вариантов группируются автоматически; при неизвестном предмете результата используется
иконка рудного блока. Радиус и ограничения частоты сканирования сохранены.

«Локальный свет» — освещение ближайших поверхностей вокруг владельца, а не изменение
гаммы всего экрана. Сила растёт от 6 до 15, радиус от 4 до 7 м. Свет плавно затухает
по расстоянию. Обновляются только соседние секции, не чаще пяти раз в секунду при
смене положения. Выключение, разрядка и смена мира убирают источник. Игровые блоки,
серверное освещение, появление мобов и рост растений не меняются. Это клиентский
источник без расчёта теней от препятствий. Ночное зрение остаётся отдельным режимом.

В пищевом отсеке теперь два резерва: заполненные и пустые капсулы. Каждый вмещает
32 единицы за уровень, до 192. Автопитание оставляет одну пустую капсулу. Если место
для тары закончилось, питание приостанавливается. Тару можно выгружать и загружать,
включая Shift-клик; один переносимый стак ограничен 64. Оба резерва сохраняются в
предмете костюма и в останках. В старых сохранениях пустой резерв начинается с нуля.

Дополнительный ряд груза находится непосредственно под обычными рядами инвентаря;
до открытия он скрыт вместе с занимаемым местом. Неоткрытый компас скрыт. HUD над
хотбаром не показывает поток ТЕ/с: там заряд, заполненность инвентаря и открытый щит.
Подробный расход доступен в меню систем.

Обновлены модели крыльев: три радужных лепестка и три раздельные гравитационные лопасти
с каждой стороны. Геометрия и атлас запекаются при загрузке ресурсов, не каждый кадр.
От первого лица остаётся обычная рука. Обычная скорость гравитационного полёта снижена
с 0.32 до 0.065 параметра полёта; ускорение — 0.16. Вертикальная скорость ограничена
0.4 блока/тик. Управление: пробел вверх, клавиша приседания (обычно Shift) вниз,
клавиша спринта (обычно Ctrl) для ускорения. Другие полётные режимы не заменяются.

## Проверка

`./tools/cloud-gradle.sh build runGameTest`

Графический клиент: Minecraft Java Edition 26.3, Fabric Loader 0.20.1, Fabric API
0.165.0+26.3, Java 25; реальный интегрированный сервер, Xorg :98 и Mesa.
`runVisualTest` управляет настоящим клиентом через Fabric Client GameTest, включая
меню, движение и снимки экрана. Отдельный визуализатор не используется.
Скриншоты новой версии хранятся в `docs/screenshots/0.8.0/`.

Результат: 40 JUnit-тестов, 88 серверных GameTest и семь клиентских сценариев прошли.
Дополнительно проверены локальный свет в закрытой тёмной комнате, поиск железа через
интерфейс фильтра, автоповтор Tab, окно дерева при 1280×720 и скорость гравиполёта.
За 20 тиков тестового движения: обычный режим 8.08 блока, ускорение 44.95 блока.
Это измерения первого отрезка с разгоном, а не установившаяся предельная скорость.

# TechMod

Индустриальный мод для **Minecraft 26.3**, **Fabric Loader 0.20.1** и
**Fabric API 0.165.0+26.3**. Требуется **Java 25**.
Основной проект находится здесь; Admuterion служит только референсом.

## Первая версия проводов

- Изолированный медный провод с объёмным восьмигранным сечением и отдельным спрайтом предмета.
- Три стабильных варианта оболочки: гладкая резина, рифление и маркировочная полоска.
  Открытый торец показывает медные жилы внутри резины.
- Размещение на полу, стенах и потолке: один провод по центру каждой грани.
  Место клика не меняет высоту трассы. Повторный клик по занятой грани не тратит предмет.
  В одной воздушной ячейке можно занять до шести разных опорных граней.
- Автоматические прямые соединения, повороты, тройники, перекрёстки,
  внутренние и внешние углы. Одиночный участок выглядит как небольшой моток.
  Участки одного ряда на соседних блоках соединяются без промежуточных кликов.
- Небольшие изгибы поверхностных трасс постоянны и не меняются при перезагрузке.
- Держатели устанавливаются в центр выбранной грани опорного блока.
  Между ними можно протянуть провод с провисанием под действием тяжести.
  Предел — **5 блоков по прямой между точками крепления**, а не длина дуги и не сумма координат.
- Пролёт проверяется на пересечение с блоками и другими подвесами до размещения.
  Занятые пролётом ячейки сохраняют данные, поэтому провод виден и выбирается
  в каждой ячейке, включая переходы через границы чанков.
- Провода и держатели поддерживают waterlogging. Вода остаётся вместе с проводом,
  течение его не смывает, после снятия последней детали вода сохраняется.
- Попытка разместить провод в лаве расходует один предмет в выживании:
  слышен звук сгорания и появляется дым. В лаве блок провода не создаётся.
- Все предметы находятся во вкладке **TechMod**. Рецептов пока нет;
  в регистрации оставлен `TODO(crafting)` для будущей системы материалов.
- Предусмотрен интерфейс `CablePort` для будущих механизмов. У совместимого
  порта модель получает металлическую соединительную муфту.

## Исправления 0.1.2

- Исправлен выбор держателя: проверка клика использует ровно ту же область,
  что и форма выделения. В 0.1.1 передняя поверхность выделения оказывалась
  за пределами прежнего допуска расстояния, и ПКМ по держателю игнорировался.
- Автотест луча выбора Minecraft проверяет все шесть ориентаций крепления;
  дополнительные проверки покрывают края, углы и несколько держателей в ячейке.
- В инвентаре используется выбранный вариант спрайта №1: медный кабель в мотке,
  текстура 128×128 с прозрачным фоном. Генератор сохраняет выбранный рисунок.
- Кэширование формы, ограниченная сетка выделения и оптимизация подвесов сохранены.

## Исправления 0.1.1

- Убрана сетка 3×3: один участок по центру грани, повторная установка бесплатна
  и ничего не добавляет. Соседние участки больше не расходятся из-за высоты клика.
- Старые участки одной грани автоматически объединяются при загрузке. Лишние
  провода возвращаются выпадением предметов (в течение секунды после загрузки).
  Если грань занята держателем, её старые поверхностные провода возвращаются полностью.
- Форма выделения кэшируется до изменения проводки. Вместо последовательного
  объединения сотен мелких объёмов заполняется одна сетка 16×16×16.
  Кэш принадлежит блочной сущности и освобождается вместе с ней.
- Подвесная кривая рассчитывается один раз на объект пролёта и повторно используется.
- Модель использует общие кольца вершин на изгибах; две половины соединения получают
  идентичный стык. В развилках добавлен закрытый узел вместо открытых торцов.
- У держателя до четырёх подключений, в ячейке до восьми подвесных пролётов.
  Превышение отклоняется до расходования предмета. Старые пролёты не удаляются.
- Нагрузочный тест охватывает восемь пролётов, старую заполненную раскладку,
  100 000 запросов выделения и 1 000 построений контура. Это тест алгоритмов
  на машине сборки, не измерение игрового FPS на компьютере пользователя.

## Управление

| Действие | Управление |
| --- | --- |
| Положить провод | ПКМ проводом по опорному блоку; провод автоматически ложится по центру грани |
| Добавить держатель | ПКМ держателем по грани блока |
| Начать подвес | ПКМ проводом по первому держателю |
| Закончить подвес | ПКМ проводом по второму держателю в радиусе 5 блоков |
| Отменить выбор | Shift + ПКМ проводом по держателю или повторный клик по первому |
| Снять отдельный провод / держатель | ПКМ кусачками по детали |
| Снять один подвес, сохранив держатель | Shift + ПКМ кусачками по держателю |
| Снять подвес в середине | ПКМ кусачками по пролёту |

Выбор первого держателя действует 60 секунд и сбрасывается при выходе игрока.
Кусачки возвращают снятые предметы в выживании. Обычное разрушение ячейки
снимает находящиеся в ней детали. Потерявшие опору участки удаляются при
проверке, выполняемой раз в секунду. Чанки принудительно не загружаются.

## Сборка и запуск

Обычная локальная среда с JDK 25:

```sh
./gradlew build
./gradlew runClient
```

JAR после **успешной** сборки: `build/libs/techmod-0.1.2.jar`.
Положите его и Fabric API в `mods` профиля Minecraft 26.3 с Fabric Loader 0.20.1.

В этой облачной среде:

```sh
./tools/cloud-gradle.sh build --no-daemon
./tools/cloud-gradle.sh runClient
```

Облачный помощник активирует установленную Java 25 и использует существующий
прокси с доверенными сертификатами среды. Проверка TLS сохраняется.
Для запуска игрового клиента нужна графическая сессия.

Независимые тесты геометрии без Minecraft и Loom:

```sh
JAVA_HOME=/path/to/jdk-25 ./tools/test-core.sh
```

Скрипт загружает JUnit с Maven Central и проверяет закреплённую SHA-512.
Текстуры уже включены в проект. Для их повторной генерации нужен Python с Pillow:
`python tools/generate_assets.py`.

## Ограничения первой версии

- Опора — полная прочная грань блока; специальные поверхности ступеней и плит не поддерживаются.
- Подвес имеет рассчитанное статическое провисание. Динамические колебания,
  натяжение от сущностей и полноценная физика верёвки пока не реализованы.
- На одной поверхности пересечения визуально объединяются. Для независимых
  трасс используйте разные грани или обход; электрической симуляции пока нет.
- Передачи энергии и самих механизмов ещё нет: `CablePort` — точка расширения.
- Предварительный призрак подвеса, подсветка отдельной детали и выбор величины
  провисания пока отсутствуют.
- Поведение в игре ещё нужно проверить по списку ниже; сборка и тесты геометрии
  не заменяют игровой проверки.

## Игровая проверка после сборки

1. Открыть вкладку TechMod: провод, держатель и кусачки имеют свои спрайты и русские названия.
2. На полу, стене и потолке разместить одиночные мотки, затем соседние участки:
   проверить прямую, поворот, тройник, перекрёсток и перестроение после снятия.
3. Проверить внутренние и внешние углы и несколько граней одной ячейки.
   Повторно кликнуть выше и ниже центра занятой грани: второй провод не создаётся,
   предмет не тратится. Снимать отдельные детали кусачками.
4. Поставить два держателя на стенах над свободным пространством. Подвесить провод
   на расстоянии ровно 5 блоков; диагональ 3–4 допустима, 4–4 должна отклоняться.
   Провисание может сделать фактическую длину больше 5.
5. Попытаться провести подвес через препятствие: предмет не должен расходоваться.
6. Повторить поверхностную и подвесную прокладку под водой. Добавить течение,
   убрать провод и проверить сохранение воды.
7. В выживании попытаться разместить провод в лаве: минус один провод, дым,
   звук, отсутствие кабельного блока. В творческом режиме запас не расходуется.
8. Сохранить и загрузить мир, проверить проводку и подвесы на границах чанков,
   подключить второго игрока и проверить синхронизацию размещения и удаления.
9. Снять держатель и разрушить опору: проверить удаление пролётов и отсутствие
   повторной выдачи предметов после выгрузки и загрузки чанков.
